# Documentacion y trazabilidad

Norma acordada: 2026-11-18 21:36:44 +01:00 (Europe/Madrid).

- Toda nueva documentacion y toda actualizacion documental debe llevar fecha,
  hora y zona horaria obtenidas del reloj al realizar el trabajo.
- Separar la hora de auditoria/verificacion de la hora de redaccion o edicion.
  Editar un informe no equivale a volver a ejecutar sus pruebas.
- Para auditorias, parches y actualizaciones de lenguajes/dependencias, aplicar
  [la norma de trazabilidad](docs/NORMA_DOCUMENTACION.md).
- No inventar horas historicas: indicar "hora no registrada" cuando falten.
- Indicar estado local/commiteado/publicado/desplegado y la evidencia de cada
  afirmacion. Un push no prueba un despliegue; distinguir comprobacion del
  agente de confirmacion del usuario.
- Consultar [el indice vigente](docs/ESTADO_TRABAJO.md) antes de retomar tareas.
  No confundir una nota historica con una prioridad o incidencia actual.
