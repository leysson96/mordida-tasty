# Impresora en tablet

## Modo actual

La web imprime tickets con el dialogo normal de Chrome/Android. El navegador abre una ventana limpia del ticket y Android decide que impresoras aparecen.

## Checklist

1. Encender la impresora y confirmar bateria/papel.
2. Emparejar la impresora por Bluetooth en ajustes de Android.
3. Instalar el servicio de impresion o app oficial del fabricante.
4. Probar impresion desde otra app Android.
5. Volver a Mordida Tasty y usar `Ajustes -> Impresora -> Ticket de prueba`.

## Si no aparece la impresora

Si Android no lista la impresora, la web no puede forzar la conexion Bluetooth. Las alternativas son usar una impresora WiFi/LAN compatible con Android Print o crear una app puente ESC/POS para impresion directa.
